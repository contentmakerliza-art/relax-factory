# Релакс-фабрика

Веб-приложение для релакс-канала. Этап 1: рендер (замена LoopForge).

Загружаете картинку или короткий клип (оживление из Kling, Seedance) и альбом MP3, нажимаете «Рендер», скачиваете готовое видео нужной длины.

Что делает рендер:
- клип зацикливается без видимой склейки: «хвост в начало» с плавным переходом или «вперёд-назад»;
- по желанию замедляет клип (после апскейла до 60 fps);
- треки идут подряд с плавными переходами, по кругу до конца видео, громкость выравнивается по EBU R128 (−14 LUFS);
- все эффекты считаются один раз на короткой петле, потом петля повторяется без перекодирования, поэтому 3 часа рендерятся почти так же быстро, как 30 секунд.

## Установка на сервер

Приложение ставится Docker-контейнером за уже работающим на сервере Traefik (тем, что обслуживает n8n) и берёт у него HTTPS-сертификаты. Остальные сервисы на сервере не меняются.

```bash
cd /opt && git clone https://github.com/contentmakerliza-art/relax-factory
DOMAIN=relax.berdykina.ru bash /opt/relax-factory/deploy/install.sh
```

В конце скрипт печатает адрес и пароль. Без `DOMAIN` адрес будет `https://<ip-через-дефисы>.sslip.io`. Обновление: `bash /opt/relax-factory/deploy/install.sh`.

- Настройки (пароль, адрес, сеть Traefik, certresolver) лежат в `deploy/.env`.
- Видео хранятся в `/var/lib/relax-factory`.
- Контейнеру выделено 1,5 ядра и 1 ГБ памяти (плюс подкачка), чтобы оставить место соседним сервисам.
- Файлы загружаются кусками по 16 МБ: Traefik обрывает слишком долгие запросы.

## Локально

```bash
pip install -r requirements.txt
APP_PASSWORD=секрет uvicorn app:app --port 8000
```

## Устройство

- `render/engine.py` — движок на ffmpeg (петля, музыка, сборка).
- `app.py` — веб-сервер (FastAPI), очередь рендера по одному видео.
- `static/index.html` — страница.

Очередь хранится в памяти: после перезапуска службы список заданий пустеет, но файлы остаются в папке данных.
