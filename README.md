# Релакс-фабрика

Веб-приложение для релакс-канала. Этап 1: рендер (замена LoopForge).

Загружаете картинку или один-несколько коротких клипов (оживление из Kling, Veo, Seedance) и альбом MP3, нажимаете «Рендер», смотрите в браузере или скачиваете готовое видео нужной длины.

Несколько клипов идут друг за другом и вместе образуют одну длинную петлю: если у каждого первый и последний кадр одинаковые, стыков не видно, а движение не повторяется каждые 10 секунд.

Вместо загрузки с компьютера можно вставить ссылку на папку Google Диска (доступ «Все, у кого есть ссылка»): сервер сам скачает клипы и треки, это намного быстрее домашнего интернета. Из папки-библиотеки можно взять несколько случайных треков («Сколько треков взять»).

«Цепочка» — для клипов, где каждый следующий сгенерирован из последнего кадра предыдущего: клипы идут подряд без размытия, плавный переход только один, в конце петли (его длина — «Переход между клипами»).

Что делает рендер:
- клип зацикливается без видимой склейки: «хвост в начало» с плавным переходом или «вперёд-назад»;
- по желанию замедляет клип (после апскейла до 60 fps);
- треки идут подряд с плавными переходами, по кругу до конца видео, громкость выравнивается по EBU R128 (−14 LUFS);
- все эффекты считаются один раз на короткой петле, потом петля повторяется без перекодирования, поэтому 3 часа рендерятся почти так же быстро, как 30 секунд.

## Установка на сервер

Приложение ставится Docker-контейнером за уже работающим на сервере Traefik (тем, что обслуживает n8n) и берёт у него HTTPS-сертификаты. Остальные сервисы на сервере не меняются.

```bash
cd /opt && git clone https://github.com/contentmakerliza-art/relax-factory
DOMAIN=relax.berdykina.ru bash /opt/relax-factory/deploy/install.sh
```

В конце скрипт печатает адрес и пароль. Без `DOMAIN` адрес будет `https://<ip-через-дефисы>.sslip.io`. Обновление: `bash /opt/relax-factory/deploy/install.sh`.

- Настройки (пароль, адрес, сеть Traefik, certresolver) лежат в `deploy/.env`.
- Видео хранятся в `/var/lib/relax-factory`.
- Контейнеру выделено 1,5 ядра и 1 ГБ памяти (плюс подкачка), чтобы оставить место соседним сервисам.
- Файлы загружаются кусками по 16 МБ: Traefik обрывает слишком долгие запросы.

## Локально

```bash
pip install -r requirements.txt
APP_PASSWORD=секрет uvicorn app:app --port 8000
```

## Устройство

- `render/engine.py` — движок на ffmpeg (петля, музыка, сборка).
- `app.py` — веб-сервер (FastAPI), очередь рендера по одному видео.
- `static/index.html` — страница.

Очередь хранится в памяти: после перезапуска службы список заданий пустеет, но файлы остаются в папке данных.

## Загрузка на YouTube с сервера

Готовое видео не нужно скачивать на компьютер. На сервере запускается Chrome, который открывается во вкладке браузера, и из него видео загружается в YouTube Studio прямо с диска сервера.

1. В консоли сервера: `bash /opt/relax-factory/deploy/browser.sh start` (не во время рендера).
2. Откройте `https://browser.<адрес приложения>`, логин `relax`, пароль как у приложения. Первый раз войдите в Google аккаунт канала.
3. В Studio «Создать → Загрузить видео», в окне выбора файла папка `/videos/<номер задания>/` (путь показан под видео в очереди).
4. Когда загрузка дошла до 100%, удалите видео в приложении и остановите браузер: `bash /opt/relax-factory/deploy/browser.sh stop`.

Браузеру выделен 1 ГБ памяти и 1 ядро, видео он видит только для чтения.
