# Релакс-фабрика

Веб-приложение для релакс-канала. Этап 1: рендер (замена LoopForge).

Загружаете картинку или короткий клип (оживление из Kling, Seedance) и альбом MP3, нажимаете «Рендер», скачиваете готовое видео нужной длины.

Что делает рендер:
- клип зацикливается без видимой склейки: «хвост в начало» с плавным переходом или «вперёд-назад»;
- по желанию замедляет клип (после апскейла до 60 fps);
- треки идут подряд с плавными переходами, по кругу до конца видео, громкость выравнивается по EBU R128 (−14 LUFS), в конце затухание;
- все эффекты считаются один раз на короткой петле, потом петля повторяется без перекодирования, поэтому 3 часа рендерятся почти так же быстро, как 30 секунд.

## Установка на сервер (Ubuntu или Debian)

```bash
curl -fsSL <ссылка на deploy/install.sh> -o install.sh
sudo REPO=<git-адрес репозитория> bash install.sh
```

Скрипт ставит ffmpeg, приложение (служба `relax-factory`) и Caddy с HTTPS по адресу `https://<ip-через-дефисы>.sslip.io`, а в конце печатает адрес и пароль. Повторный запуск обновляет код, пароль и видео сохраняются. Свой домен: `DOMAIN=video.example.com`.

Пароль лежит в `/etc/relax-factory.env`, видео в `/var/lib/relax-factory`.

## Локально

```bash
pip install -r requirements.txt
APP_PASSWORD=секрет uvicorn app:app --port 8000
```

## Устройство

- `render/engine.py` — движок на ffmpeg (петля, музыка, сборка).
- `app.py` — веб-сервер (FastAPI), очередь рендера по одному видео.
- `static/index.html` — страница.

Очередь хранится в памяти: после перезапуска службы список заданий пустеет, но файлы остаются в папке данных.
