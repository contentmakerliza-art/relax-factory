## Производство

Английская озвучка — голос Aleksandr в ElevenLabs через SYNTX. Русская версия по отдельному запросу, голос Егор. Сначала проверяем факты и пишем историю, затем записываем голос и привязываем действия к репликам. Обычный план длится около 3–5 секунд, сложное действие показываем до результата. Для каждого выпуска делаем 12–15 разных клипов Runway при подтверждённой цене 0 токенов. Карты, схемы, титры и простые движения анимируем локально. Каждый план используется один раз. Для возвращения к герою или месту создаём другой ракурс. Проверяем анатомию, контакты, стабильность героев, произношение и синхронизацию. Передаём чистый мастер 1080p, английские SRT и копию с субтитрами. Topaz применяем выборочно после сравнения. Публикация вручную.
